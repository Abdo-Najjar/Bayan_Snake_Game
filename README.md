# Bayan vs the Snake

A pygame chase game: help Bayan collect gems across 9 levels while snakes hunt her down,
then defeat the giant snake in its lair.

## Run

```bash
pip install -r requirements.txt
python main.py
```

Or double-click `run_game.bat` on Windows. `python -m bayan_game` also works.

## Controls

| Key | Action |
|---|---|
| Arrows / WASD | Move |
| Space / Shift | Dash (Bayan can't be caught while dashing) |
| P / Esc | Pause |
| F11 | Toggle full screen |
| Mouse | Menus, shop, settings |

## Features

- A step-by-step tutorial (moving, gems, dash, power-ups, a slow practice snake). It runs the first
  time you press Play, and you can replay it from the main menu. Esc skips it.
- 9 levels across 5 terrains: meadow, desert (quicksand), snow (slippery), forest (bushes to hide in), and the boss lair
- 4 snake types: normal, small & fast, lunger (telegraphs then lunges), poison (leaves slowing puddles)
- Boss fight: the giant snake charges in a straight line; make it crash into rocks 3 times
- Power-ups: speed, shield, freeze, invisibility
- 1-3 stars per level, coins, and an outfit shop (dresses, bow, flower, cap, hijab, crown)
- Settings: music / sound volume, full screen, difficulty, language
- PNG sprites for Bayan (4-frame walk in 3 directions, outfits tinted at runtime),
  every snake type, the boss, and the power-up / HUD icons (generated by `tools/`, replaceable)
- Different music for every level (its own key, scale, tempo, instrument and drums: the desert
  uses the Hijaz maqam) plus an ambience loop per terrain
- Arabic and English, and more languages can be added through JSON files

## Adding a language

1. Copy `bayan_game/assets/lang/en.json` to e.g. `fr.json`.
2. Set `_meta.name` (shown in Settings) and `_meta.rtl` (`true` for right-to-left scripts).
3. Translate the values and keep the keys. `{placeholders}` must stay as they are.

The new language shows up in Settings automatically. Missing keys fall back to English.

## Adding or tuning a level

Edit `LEVELS` in `bayan_game/content/levels.py`, then add a `level_tips.<index>` entry to every
language file. Global tuning (speeds, power-up durations, rewards) lives in `bayan_game/config.py`.

## Replacing art and music

Every asset is a normal file, so you can swap in hand-drawn art or real recordings:

- **Bayan** (`assets/sprites/bayan/<down|up|side>/<layer>.png`): each layer is a strip of 5 frames
  (idle + 4 walk), 256x320 each. The feet sit at pixel (128, 200) of a frame. Grey layers
  (`dress`, `hijab_*`, `hat_cap`) are tinted with the outfit colour, so draw them in greys.
  The side view faces right and is mirrored for left.
- **Snakes** (`assets/sprites/snakes/<kind>_head.png`, `<kind>_body.png`): heads are 3 frames
  (open, closed, angry) facing right; bodies are 2 segment frames.
- **Icons** (`assets/sprites/icons/<name>.png`): 128x128, scaled down in game.
- **Music / ambience**: drop `level_3.ogg` (or `.mp3` / `.wav`) next to the others. A file
  with the same name is used instead of the generated one (`.ogg` wins over `.wav`).

To regenerate the built-in assets:

```bash
pip install -r requirements-dev.txt
python -m tools.build_assets           # everything
python -m tools.build_assets sprites   # or: audio
```

## Tests

```bash
python -m unittest discover tests
```

The tests run without a window. They play through every level and the tutorial, check that
every sprite, music track and ambience loop exists, check that the language files have matching
keys, and check that no Arabic text sits in the Python code.

Progress is saved in `save.json` (ignored by git). Delete it to start over.
